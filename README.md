# OmniSales - Real-Time Sales Analytics Dashboard

A responsive, single-page executive sales analytics dashboard built with vanilla HTML, CSS, and JavaScript.

## Features
- **Zero CSS Variables**: Styled using pure vanilla CSS with explicit color mappings.
- **Client-Side Persistence**: Persistent data storage via HTML5 `localStorage` (no backend required).
- **Executive KPIs**: Real-time Gross Revenue, Net Sales, Total Transactions, Average Order Value (AOV), and Refunds tracking.
- **Quota Tracking**: Visual monthly quota milestone progress bar.
- **Interactive Visualizations (Chart.js)**:
  - Daily revenue trajectory & order volume timeline
  - Product category distribution doughnut chart
  - Top revenue streams bar chart
  - Payment gateway breakdown
- **Full Ledger Management**:
  - Live search across invoice ID, customer, email, and product
  - Category and status filtering
  - Multi-field sorting & pagination
  - Add/delete sales records with instant UI & KPI updates
  - CSV export of sales records
  - One-click demo data reset

## Getting Started
Simply open `index.html` in any modern web browser.
